# Retail Detective AI

## Project Description

Retail Detective AI is an AI-powered Business Intelligence System that helps businesses analyze retail datasets.

## Features

- Upload CSV/Excel Dataset
- Automatic Data Cleaning
- Exploratory Data Analysis
- Interactive Dashboard
- Sales Prediction
- Customer Segmentation
- AI Chatbot
- Business Insights
- PDF Report Generation

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Matplotlib
